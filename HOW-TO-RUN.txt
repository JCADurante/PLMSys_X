================================================================================
PLMSys - HOW TO RUN ON WINDOWS / LINUX / MACOS
================================================================================

--------------------------------------------------------------------------------
PORTABLE STANDALONE NODE.JS (ZERO INSTALLATION REQUIRED)
--------------------------------------------------------------------------------
If you do NOT want to install Node.js on your computer (or don't have admin rights):
1. Download standalone `node.exe` (e.g. from https://nodejs.org/dist/latest/win-x64/node.exe or the official Node.js .zip package).
2. Place `node.exe` directly inside the PLMSys folder.
3. Double-click `START.bat`.
   - `START.bat` will automatically detect the local `node.exe` and start `server.js` without any installation or system configuration needed!
   - `server.js` has zero external npm dependencies and runs 100% offline.

--------------------------------------------------------------------------------
QUICK START (WINDOWS)
--------------------------------------------------------------------------------
1. Extract the downloaded ZIP file to a folder (e.g. C:\PLMSys).
2. Double-click START.bat (or INSTALL-AND-RUN.bat)
   - It will install packages, build the bundle if needed, and start the server.
   - It will automatically launch http://localhost:3000 in your browser.
   - Other phones, tablets, and PCs on your Wi-Fi/LAN can open:
     http://<YOUR_PC_IP>:3000

--------------------------------------------------------------------------------
HELPER SCRIPTS INCLUDED
--------------------------------------------------------------------------------
- START.bat: Standard one-click server starter.
- INSTALL-AND-RUN.bat: Automated first-time setup (runs npm install & build & server).
- CHECK-NETWORK.bat: Checks if your Wi-Fi is Public or Private, and lets you switch to Private & open port 3000 with 1 click.
- DIAGNOSE.bat: Diagnostic tool to check your Node.js, firewall, and LAN IP.

--------------------------------------------------------------------------------
TROUBLESHOOTING & COMMON SOLUTIONS
--------------------------------------------------------------------------------

1. "THIS SITE CANNOT BE REACHED" FROM PHONE / TABLET:
   - Double-click CHECK-NETWORK.bat and choose option [3] to set your network to Private and open port 3000.

2. RUNNING FROM INSIDE THE .ZIP FILE:
   - If you double-click START.bat from inside a zip, extract all files first!
   - Right-click the zip file -> "Extract All..." -> Open the extracted folder.

3. WINDOWS SMARTSCREEN WARNING:
   - Click "More info" -> "Run anyway".

4. MANUAL RUN VIA COMMAND PROMPT:
   - Open your project folder in File Explorer.
   - Click the top address bar, type "cmd" and press Enter.
   - Type:
       node server.js
     and press Enter.
